<h2>1️⃣ Retail Business Performance & Profitability Analysis</h2>
<p><strong>Objective:</strong> Analyze transactional retail data to uncover profit-draining categories, optimize inventory turnover, and identify seasonal product behavior.</p>

<ul>
  <li><strong>Tools:</strong> SQL, Python (Pandas, Seaborn), Tableau</li>
  <li><strong>Process:</strong>
    <ul>
      <li>Imported and cleaned data in SQL</li>
      <li>Calculated profit margins by category & sub-category</li>
      <li>Used Python (Pandas) for correlation between inventory days & profitability</li>
      <li>Built Tableau dashboard with filters for region, product type, and season</li>
      <li>Derived strategic suggestions for slow-moving and overstocked items</li>
    </ul>
  </li>
  <li><strong>Deliverables:</strong> Tableau Dashboard, SQL Queries (.sql file), PDF Report with key insights</li>
</ul>

<h2>2️⃣ E-commerce Return Rate Reduction Analysis</h2>
<p><strong>Objective:</strong> Identify why customers return products and how return rates vary by category, geography, and marketing channel.</p>

<ul>
  <li><strong>Tools:</strong> Python, Power BI, SQL</li>
  <li><strong>Process:</strong>
    <ul>
      <li>Cleaned return and order datasets</li>
      <li>Analyzed return % per category and supplier</li>
      <li>Built logistic regression model to predict probability of return</li>
      <li>Created Power BI dashboard with return risk score and drill-through filters</li>
    </ul>
  </li>
  <li><strong>Deliverables:</strong> Interactive Power BI Dashboard, Python Codebase for prediction, CSV of high-risk products</li>
</ul>
